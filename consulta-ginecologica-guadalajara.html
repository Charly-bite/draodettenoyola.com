Motivos de Consulta Frecuentes

¿Cuándo Debes Acudir con la Ginecóloga?

No normalices el dolor ni los cambios menstruales. Agenda tu valoración si presentas cualquiera de las siguientes condiciones:

✓ Irregularidades menstruales (retrasos o sangrados abundantes)
✓ Síndrome de Ovario Poliquístico (SOP) y resistencia a la insulina
✓ Dolor pélvico o cólicos menstruales intensos (Dismenorrea)
✓ Sospecha o diagnóstico de Endometriosis
✓ Miomas uterinos y pólipos endometriales
✓ Infecciones vaginales recurrentes (candidiasis, vaginosis)
✓ Detección, manejo y seguimiento de Virus del Papiloma Humano (VPH)
✓ Dolor durante las relaciones sexuales (Dispareunia)
✓ Colocación y retiro de DIU o Implante Anticonceptivo
✓ Síntomas de Climaterio, Perimenopausia y Menopausia
✓ Consulta preconcepcional y preparación para el embarazo
✓ Chequeo ginecológico preventivo anual
